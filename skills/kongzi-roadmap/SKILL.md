# Kongzi roadmap

From the Kongzi skill root, read `evidence-protocol.md`, `learning-science.md`, and `operating-protocol.md` in the `references` directory.

Extract bounded claims with locators. Decompose the target outcome into nodes of type concept, fact, procedure, mental-model, or metacognitive. Every authoritative node should reference supporting claim IDs.

Encode true prerequisites with repeated `--prerequisite`; avoid a flat topic list. Give each node a demonstrable outcome. Run `map render`, then `plan build`.

Choose teaching methods by knowledge type and learner evidence. Include retrieval, spacing, feedback, and transfer in every plan; add worked-example fading, interleaving, apprenticeship, or projects only where appropriate. The Feynman-style explanation is one diagnostic/output technique, not the universal plan.

Present the roadmap to the learner and invite one bounded correction before beginning.
