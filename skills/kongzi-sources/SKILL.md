# Kongzi sources

From the Kongzi skill root, read `evidence-protocol.md` and `integration-contracts.md` in the `references` directory.

Accept Markdown, text, HTML, EPUB, and PDF when `pdftotext` is available. Register local material with `source add`; retrieve public pages with `source fetch`. Prefer primary/official sources and preserve publication/access metadata.

For long books or transcripts, use the complete Cangjie integration. For supported video URLs, run video-downloader first, then Cangjie. Never treat a transcript or distillation as automatically true: create claims with locators and appropriate authority/status.

Before building a roadmap, require enough material to cover the learner's target outcome. Show gaps explicitly and retrieve or request missing sources.
