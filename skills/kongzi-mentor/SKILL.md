# Kongzi mentor

From the Kongzi skill root, read `integration-contracts.md` and `evidence-protocol.md` in the `references` directory.

If the learner requests a real person as mentor, use the full Nuwa workflow: disambiguate, research all six dimensions, use more than half primary sources, create 3–7 operational models, include provenance and honest boundaries, then import the persona.

The persona may shape tone, heuristics, examples, and questions. It cannot override Kongzi claims, quote a person without a source, or pretend the real person is present. If no Nuwa persona is needed, `mentor set` can activate a learner-supplied persona file.
