# Product

Status: CONFIRMED

## Purpose

Kongzi is a local-first Agent Skills suite that helps one person learn any
knowledge domain through a source-backed, personalized loop: define capability,
diagnose prior knowledge, establish authoritative material, map prerequisites,
plan, require learner output, assess, schedule review, and report evidence.

The first interface is command driven. Bare `/Kongzi` starts or resumes the
complete journey and recommends one next action. Obsidian is the default
knowledge-base experience. The project is for personal use and does not include
billing, multi-user SaaS, growth features, or a GUI in the initial scope.

## Product truths

- Reading AI output is not treated as learning.
- Every substantive study session requires learner output.
- Factual knowledge must remain traceable to a source and locator.
- Personalization uses goals, prerequisites, observed performance, errors,
  retention, time, and constraints—not unsupported learning-style labels.
- Progress means delayed retrieval and application evidence, not time spent or
  note volume.
- Conversation history is not durable memory; local files are.
- Mentor personas are optional reasoning lenses and cannot override evidence or
  grading.
- Command-first dogfooding precedes any GUI work.
