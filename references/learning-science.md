# Learning-science selection guide

Kongzi does not use one universal technique. Select methods from the knowledge type, learner evidence, and target performance.

| Method | Strong use | Poor use or caveat |
|---|---|---|
| Retrieval practice / testing effect | Durable recall, concept discrimination, prerequisite checks | Bad questions can rehearse errors; always correct |
| Spaced practice | Retention across days and months | It does not choose what to practice |
| Interleaving | Choosing among similar procedures/categories | Too early can overload a complete novice |
| Worked examples + fading | Initial procedural learning and problem solving | Passive copying is insufficient; fade support |
| Self-explanation | Connecting steps, assumptions, and prior knowledge | Needs prompts/rubrics to avoid fluent nonsense |
| Elaboration | Explaining why/how and building examples | Unsupported elaboration can create misconceptions |
| Dual coding | Spatial/structural relationships plus verbal models | Decorative visuals do not improve learning |
| Deliberate practice | Bounded skills with feedback and repeated correction | Not a complete theory of all learning |
| Mastery learning | Prerequisite-heavy curricula with corrective loops | Requires meaningful mastery criteria |
| Cognitive apprenticeship | Tacit procedures through model, coach, scaffold, fade | Needs authentic tasks and expert feedback |
| Project/problem-based learning | Integration, transfer, creation | Novices still need explicit guidance |
| Metacognitive calibration | Planning, monitoring, comparing confidence with score | Self-report alone is unreliable |
| Feynman-style explanation | Revealing gaps and simplifying explanations | Not universal; does not replace practice, sources, or feedback |

## Decision rules

- **Facts and terminology:** retrieval + spacing + discrimination.
- **Concepts and mental models:** examples/non-examples + self-explanation + retrieval + transfer.
- **Procedures:** worked example → completion problem → independent practice → varied application.
- **Perceptual/category judgments:** contrasting cases + interleaving + rapid feedback.
- **Creative or professional performance:** component practice + critique + real project + reflection.
- **Tacit practice:** expert modeling + coached attempt + fading + authentic task.

## Evidence anchors

Use these public papers and reviews as starting points, then register the actual page or file in the learner's current journey:

| Area | Public source | Evidence note |
|---|---|---|
| Retrieval | Roediger & Karpicke (2006), [Test-enhanced learning](https://doi.org/10.1111/j.1467-9280.2006.01693.x) | Strong delayed-retention evidence |
| Retrieval transfer | Butler (2010), [Repeated testing produces superior transfer](https://doi.org/10.1037/a0019902) | Supports fresh inferential questions |
| Retrieval vs mapping | Karpicke & Blunt (2011), [Retrieval practice produces more learning](https://doi.org/10.1126/science.1199327) | Retrieval outperformed elaborative concept mapping in the studied conditions |
| Spacing | Cepeda et al. (2006), [Distributed practice review and quantitative synthesis](https://doi.org/10.1037/0033-2909.132.3.354) | Strong synthesis; useful gap depends on retention horizon |
| Spacing interval | Cepeda et al. (2008), [Temporal ridgeline of optimal retention](https://doi.org/10.1111/j.1467-9280.2008.02209.x) | Longer desired retention generally calls for a longer gap |
| Interleaving | Rohrer & Taylor (2007), [Shuffling mathematics problems improves learning](https://doi.org/10.1007/s11251-007-9015-8) | Especially relevant to strategy/category selection |
| Self-explanation | Chi et al. (1989), [Self-explanations in learning from examples](https://doi.org/10.1207/s15516709cog1302_1) | Supports explaining steps, mechanisms, and gaps |
| Worked examples | Sweller & Cooper (1985), [Worked examples as a substitute for novice problem solving](https://doi.org/10.1207/s1532690xci0201_3) | Strongest in structured novice domains |
| Mastery learning | Kulik et al. (1990), [Meta-analysis of mastery learning programs](https://doi.org/10.3102/00346543060002265) | Positive average effects with time/cadence costs |
| Feedback | Hattie & Timperley (2007), [The power of feedback](https://doi.org/10.3102/003465430298487) | Feedback effects depend strongly on level and delivery |
| Feedback synthesis | Wisniewski et al. (2020), [The power of feedback revisited](https://pmc.ncbi.nlm.nih.gov/articles/PMC6987456/) | Large variability; generic praise is not enough |
| Active learning | Freeman et al. (2014), [Active learning in undergraduate STEM](https://doi.org/10.1073/pnas.1319030111) | Strong domain-bounded meta-analysis |
| Self-regulation | Zimmerman (2002), [Becoming a self-regulated learner](https://doi.org/10.1207/S15430421TIP4102_2) | Useful plan–perform–reflect cycle |
| Deliberate practice | Macnamara et al. (2014), [Deliberate practice and performance meta-analysis](https://doi.org/10.1177/0956797614535810) | Important but far from a universal explanation |
| Knowledge tracing | Corbett & Anderson (1995), [Knowledge tracing](https://doi.org/10.1007/BF01099821) | Useful model basis; estimates depend on assumptions |
| Technique review | Dunlosky et al. (2013), [Effective learning techniques](https://doi.org/10.1177/1529100612453266) | Practice testing and distributed practice rated high utility |
| Learning styles boundary | Pashler et al. (2008), [Learning styles: Concepts and evidence](https://doi.org/10.1111/j.1539-6053.2009.01038.x) | Does not support matching instruction to VAK-style labels |

The named “Feynman technique” is not a universal research protocol. Kongzi uses its useful core—closed-book self-explanation and gap detection—inside retrieval, source comparison, corrective feedback, delayed retesting, and domain-specific practice.

Do not present this bibliography as proof by itself. A current journey must resolve the relevant paper, publisher page, book excerpt, or official source and register it with a locator before using its claims to teach or grade.
